Site information

Privacy

Last updated: August 8, 2026. The free utilities under /tools/ are designed to process their working inputs locally in your browser. Tool inputs such as pasted text, passwords, QR content, dates and conversion values are not sent to the website backend by the tool code.

Reader activity

The site may use limited browser-local identifiers and a Cloudflare-backed database for aggregate paper readership and reader reactions. These systems are separate from tool inputs. Tool input values are not written to those analytics tables.

Local browser features

Some interactions use browser APIs such as the clipboard, Web Crypto and local browser state. Clipboard contents and browser extensions are controlled by your browser/device, not by this website.

Third-party links

External links, including publisher, GitHub, Scholar or Wikipedia links, are governed by those services' own privacy practices.

Questions about this site can be sent through the website contact page.
