# Search visibility deployment checklist

The site is configured for crawling and entity recognition, but no code can guarantee a first-page Google ranking.

After deployment:

1. Verify **Domain property** `umairdanish.com` in Google Search Console.
2. Submit `https://umairdanish.com/sitemap.xml`.
3. Inspect `https://umairdanish.com/` and request indexing.
4. Inspect `https://umairdanish.com/about.html` and `https://umairdanish.com/publications.html` and request indexing after the homepage is accepted.
5. Add `https://umairdanish.com/` as the website URL on Google Scholar, ORCID, LinkedIn, ResearchGate, and other academic profiles you control.
6. Ask Western University to link to the canonical personal website from an official profile page when appropriate.
7. Keep name/affiliation wording consistent: **Muhammad Umair Danish, PhD**, Postdoctoral Fellow in Applied AI, Western University.

Do not create doorway pages, duplicate keyword pages, paid link schemes, hidden text, or fake citations/backlinks.
