Core-Norm

Bounded, asymmetric and invertible preprocessing for numeric machine-learning features—designed to limit the numerical leverage of extremes without discarding their magnitude.

Python · scikit-learn compatibleExact inverse for valid encodingsLocal browser demoMIT licensed
Research status, not a universal replacement.

Core-Norm is a method under active validation. The benchmark below is preliminary internal evidence; some distributions and learners can still favor established transformations.

HOW IT WORKS

Separate numerical stability from tail information.

Core-Norm fits robust, side-specific feature statistics on training data. Ordinary values remain approximately linear inside a bounded central coordinate, while excess magnitude is retained in a second bounded residual coordinate with a closed-form inverse.

01

Robust centre

Use the median rather than a mean dominated by extreme observations.

m = Q₀.₅₀(x)
02

Asymmetric scale

Estimate lower and upper spread separately instead of forcing both sides through one scale.

s⁻ = m-Q₀.₂₅ · s⁺ = Q₀.₇₅-m
03

Bounded central coordinate

Keep the main numeric geometry inside a finite interval.

C = clip(u/τ, -1, 1)
04

Invertible residual

Compress excess tail distance monotonically rather than deleting it through hard clipping.

R = sign(u) · log(1+d)/(1+log(1+d))

PRELIMINARY VALIDATION

Robustness under increasing feature corruption.

The archived Phase-1 benchmark contains 12,150 saved model/scaler evaluations. The strongest observed pattern was slower degradation under synthetic extreme corruption. The numbers below are development evidence, not peer-reviewed performance guarantees.

The benchmark also contains negative results: static preprocessing did not solve compound distribution shift, and some clean/skewed classification settings favored established transforms. Those limitations are retained in the repository rather than hidden.

VERIFIED PROPERTIES

Designed to be inspectable, not magical.

The implementation exposes the fitted state and inverse explicitly. Development QA also ran a 700,000-scalar forward/inverse stress test across Gaussian, skewed, heavy-tailed, bimodal, zero-inflated and contaminated data.

Bounded

The central coordinate stays in [-1,1] and the residual stays strictly inside (-1,1) for finite inputs.

Invertible

The residual has a closed-form inverse. The 700,000-value stress test had worst absolute reconstruction error ≈ 2.44×10⁻¹⁰ on ordinary test scales.

Side-specific

Lower and upper quartile spreads are estimated separately, allowing asymmetric feature distributions without forcing Gaussianization.

from corenorm import CoreNorm

scaler = CoreNorm().fit(X_train)
X_train_core = scaler.transform(X_train)
X_test_core  = scaler.transform(X_test)
X_again      = scaler.inverse_transform(X_train_core)
