AlgoLens

Static time & space complexity analyzer. Paste or upload code and receive an inspectable asymptotic estimate, loop/recurrence evidence, space model, confidence, and limitations.

Big-OStatic analysisAST-like reasoningLocal-firstNo server upload
Inspect the reasoning, not only the answer.

The engine exposes loop/recurrence evidence, assumptions, and uncertainty. Arbitrary-program complexity is not mathematically decidable, so difficult cases are labelled as estimates rather than presented as proofs.

LIVE WORKBENCH

Run it on code now.

Use a built-in case, upload a source file, or paste code directly. The current engine emphasizes Python and recognizes common Java, JavaScript, C and C++ loop patterns.

Code input

local only

Paste code, upload a source file, or choose a built-in verification fixture. No source code is transmitted by this page.
